# Slurry-Bioprinting-Hardware

Ender 3 conversion with a Poseidon-style syringe pump for printing slurry-based engineered living materials.

- `STLs/` original printed parts (`pump_body_main.STL`, `plunger_carriage_retraction.STL`) and test models
- `gcode/` original test prints
- **[`v2/`](v2/README.md): redesigned parts, sensors and an India-specific build guide and BOM**
